# **Wanderlii - ** 🏡✈️  

**Wanderlii** is a web application inspired by Airbnb, developed using the **MERN (MongoDB, Express.js, EJS, Node.js) stack**. This platform allows users to browse, search, and book accommodations with a **responsive and seamless experience** across all devices.  

## **🚀 Features**  
- 🔐 **User Authentication** – Secure signup, login, and profile management.  
- 🏠 **Accommodation Listings** – View details, photos, pricing, and availability of various accommodations.  
- 🔍 **Search Functionality** – Filter accommodations based on **location, date, price, and amenities**.  
- 📅 **Booking System** – Easily book accommodations within available dates.  
- 📱 **Responsive Design** – Optimized for **desktops, tablets, and mobile phones**.  

## **🛠️ Technologies Used**  
- **MongoDB** – Stores accommodation, user, and booking data.  
- **Express.js** – Handles server-side operations and API routes.  
- **EJS** – Builds an interactive and dynamic frontend UI.  
- **Node.js** – Runs JavaScript code on the server-side.  
- **Bootstrap** (or any responsive framework) – Ensures mobile-friendly UI.  
- **HTML/CSS** – Provides styling and structure to the web interface.
